# WPILib struct types nt4-wpimath doesn't have, for scripts/schema_audit.py.
# One per line: `<name> todo|na  # reason`. Generic types are written with
# their C++ parameters in angle brackets, as the audit prints them.
#
# nt4-wpimath carries the types Rust programs publish or read: geometry,
# drive state, trajectory samples, shapes, and swerve kinematics. The rest
# are marked `na`: read them with nt4_proto::structs (which decodes any
# struct from its /.schema/ topic at run time), or derive your own with
# #[derive(NtStruct)]. Any of them can move to `todo` if someone asks.
# Decided 2026-11-16.
